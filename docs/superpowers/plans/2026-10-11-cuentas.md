# Cuentas con usuario y contraseña (parte A) · Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cuentas propias con email y contraseña (opcionales para navegar, obligatorias para pagar), historial de
pedidos, carrito por usuario en `localStorage` y admin decidido por `Usuario.rol`, creado solo con `npm run crear-admin`.

**Architecture:** Contraseñas con scrypt (`node:crypto`). Sesión propia: tabla `Sesion` cuyo id es el SHA-256 de un
token aleatorio que viaja en la cookie `httpOnly` `sesion_rincon`. `usuarioActual()` (cacheado por petición) lee la
cookie y la BD; `exigirAdmin()` mira el rol en la BD. El middleware solo comprueba que exista la cookie. El carrito
sigue en Zustand + `persist`, con una clave por identidad y `SincronizarCarrito` sumando el anónimo al entrar.

**Tech Stack:** Next.js 15.5 (App Router, Server Actions, `useActionState`), TypeScript, Prisma 7 (Neon), Zustand 5,
Vitest. Sin dependencias nuevas.

**Spec:** `docs/superpowers/specs/2026-10-11-cuentas-design.md`

3. **`callbackUrl` hacia otro dominio** (`//malo.com`, `https://malo.com`, `/\malo.com`): se vuelve a `/`. Test de

4. **Cookie con una sesión caducada o borrada** (por ejemplo tras `npm run seed`): `usuarioActual()` da `null` y las

5. **Registro con el mismo email dos veces a la vez** (doble clic): la restricción `@unique` gana; la segunda petición
   recibe "Ya hay una cuenta con ese email: entra", no un error 500. Captura de `P2002` en `registrarse` (Tarea 5).

```ts
// Reglas de las cuentas de cliente: funciones puras, sin BD ni Node, para poder testearlas (tests/cuentas.test.ts)
// y usarlas tambien en componentes cliente. Lo criptografico esta en src/lib/contrasenas.ts.
export type Rol = "CLIENTE" | "ADMIN";

// Nombre de la cookie de sesion. Aqui (y no en sesion.ts) porque el middleware no puede importar Prisma.
export const COOKIE_SESION = "sesion_rincon";

export const MINIMO_CONTRASENA = 8;
// scrypt con un texto enorme es caro: se corta antes de calcular nada
export const MAXIMO_CONTRASENA = 200;
const MAXIMO_NOMBRE = 80;
const FORMATO_EMAIL = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;

export type ResultadoRegistro = { ok: true; datos: { nombre: string; email: string } } | { ok: false; error: string };

// Comprueba el formulario de registro y devuelve el PRIMER error, en español, o los datos ya limpios.
export function validarRegistro(d: { nombre: string; email: string; contrasena: string; repetir: string }): ResultadoRegistro {
  const nombre = d.nombre.trim();
  const email = d.email.trim().toLowerCase();
  if (!nombre) return { ok: false, error: "Escribe tu nombre" };
  if (nombre.length > MAXIMO_NOMBRE) return { ok: false, error: "El nombre es demasiado largo" };
  if (!FORMATO_EMAIL.test(email)) return { ok: false, error: "Escribe un email válido" };
  if (d.contrasena.length < MINIMO_CONTRASENA) {
    return { ok: false, error: `La contraseña necesita al menos ${MINIMO_CONTRASENA} caracteres` };
  }
  if (d.contrasena.length > MAXIMO_CONTRASENA) {
    return { ok: false, error: `La contraseña es demasiado larga (máximo ${MAXIMO_CONTRASENA} caracteres)` };
  }
  if (d.contrasena !== d.repetir) return { ok: false, error: "Las contraseñas no coinciden" };
  return { ok: true, datos: { nombre, email } };
}

// Un pedido lo ve su dueño o un admin. Los pedidos de antes de las cuentas (sin dueño) solo los ve el admin.
export function puedeVerPedido(usuario: { id: number; rol: Rol }, pedido: { usuarioId: number | null }): boolean {
  return usuario.rol === "ADMIN" || (pedido.usuarioId !== null && pedido.usuarioId === usuario.id);
}

// A donde volver tras entrar: solo rutas de la propia tienda. "//x.com" o "/\x.com" saldrian a otro dominio.
export function destinoSeguro(valor: string | null | undefined): string {
  if (!valor || !valor.startsWith("/") || valor.startsWith("//") || valor.startsWith("/\\")) return "/";
  return valor;
}
```

```ts
// Criptografia de las cuentas, con node:crypto (sin dependencias). Solo servidor.
//  - Contraseñas: scrypt con una sal aleatoria por usuario. Se guarda "sal:hash" en hexadecimal, nunca el texto.
//  - Tokens de sesion: en la BD se guarda su SHA-256, asi quien lea la BD no puede fabricar cookies validas.
import { createHash, randomBytes, scrypt, timingSafeEqual } from "node:crypto";

const LARGO_HASH = 64;
const LARGO_SAL = 16;

function scryptAsync(texto: string, sal: Buffer): Promise<Buffer> {
  return new Promise((resolve, reject) =>
    scrypt(texto, sal, LARGO_HASH, (error, hash) => (error ? reject(error) : resolve(hash))),
  );
}

export async function cifrarContrasena(texto: string): Promise<string> {
  const sal = randomBytes(LARGO_SAL);
  const hash = await scryptAsync(texto, sal);
  return `${sal.toString("hex")}:${hash.toString("hex")}`;
}

// timingSafeEqual: compara en tiempo constante, para no dar pistas por lo que tarda
export async function comprobarContrasena(texto: string, guardada: string): Promise<boolean> {
  const partes = guardada.split(":");
  if (partes.length !== 2) return false;
  const [salHex, hashHex] = partes;
  if (!/^[0-9a-f]{32}$/.test(salHex) || !/^[0-9a-f]{128}$/.test(hashHex)) return false;
  const calculado = await scryptAsync(texto, Buffer.from(salHex, "hex"));
  return timingSafeEqual(calculado, Buffer.from(hashHex, "hex"));
}

export function huellaToken(token: string): string {
  return createHash("sha256").update(token).digest("hex");
}
```

```ts
// Al entrar: el carrito anonimo se SUMA al del usuario. Mismo producto = una linea, sin pasar del stock
// (el mayor de los dos guardados). De una linea repetida se quedan los datos del anonimo, que son los mas recientes.
export function juntarCarritos(anonimo: LineaCarrito[], usuario: LineaCarrito[]): LineaCarrito[] {
  const resultado = usuario.map((l) => ({ ...l }));
  for (const a of anonimo) {
    const i = resultado.findIndex((l) => l.id === a.id);
    if (i === -1) {
      resultado.push({ ...a, cantidad: Math.min(a.cantidad, a.stock) });
    } else {
      const stock = Math.max(resultado[i].stock, a.stock);
      resultado[i] = { ...a, stock, cantidad: Math.min(resultado[i].cantidad + a.cantidad, stock) };
    }
  }
  return resultado.filter((l) => l.cantidad > 0);
}
```

```ts
// Sesiones propias: un token aleatorio en una cookie httpOnly y su SHA-256 en la tabla Sesion.
// Sustituye a la vieja contraseña compartida del admin. Solo servidor.
import "server-only";
import { randomBytes } from "node:crypto";
import { cookies } from "next/headers";
import { cache } from "react";
import { huellaToken } from "@/lib/contrasenas";
import { COOKIE_SESION } from "@/lib/cuentas";
import { prisma } from "@/lib/prisma";

const DURACION_MS = 30 * 24 * 60 * 60 * 1000; // 30 dias

// Abre una sesion y pone la cookie. Solo desde una Server Action (un Server Component no puede escribir cookies).
export async function iniciarSesion(usuarioId: number) {
  const token = randomBytes(32).toString("hex");
  const caduca = new Date(Date.now() + DURACION_MS);
  // De paso, limpiamos las sesiones caducadas de este usuario
  await prisma.sesion.deleteMany({ where: { usuarioId, caduca: { lt: new Date() } } });
  await prisma.sesion.create({ data: { id: huellaToken(token), usuarioId, caduca } });
  (await cookies()).set(COOKIE_SESION, token, {
    httpOnly: true, // JavaScript del navegador no puede leerla
    sameSite: "lax",
    secure: process.env.NODE_ENV === "production", // solo por HTTPS en produccion
    path: "/",
    expires: caduca,
  });
}

// Quien ha entrado, leido de la BD, sin el hash de la contraseña.
// cache(): layout, cabecera y pagina lo piden en la misma peticion, pero se consulta la BD una sola vez.
export const usuarioActual = cache(async () => {
  const token = (await cookies()).get(COOKIE_SESION)?.value;
  if (!token) return null;
  const sesion = await prisma.sesion.findUnique({
    where: { id: huellaToken(token) },
    include: { usuario: { omit: { contrasena: true } } },
  });
  if (!sesion || sesion.caduca < new Date()) return null;
  return sesion.usuario;
});

export type UsuarioSesion = NonNullable<Awaited<ReturnType<typeof usuarioActual>>>;

// El rol se lee de la BD en cada peticion: cambiarlo tiene efecto al momento.
// OJO: el middleware solo mira que exista la cookie. Cada pagina y cada accion de admin llama a exigirAdmin().
export async function exigirAdmin() {
  const usuario = await usuarioActual();
  return usuario?.rol === "ADMIN" ? usuario : null;
}

// Cierra la sesion de verdad: se borra la fila (la cookie deja de valer aunque alguien la hubiera copiado)
export async function cerrarSesion() {
  const almacen = await cookies();
  const token = almacen.get(COOKIE_SESION)?.value;
  if (token) await prisma.sesion.deleteMany({ where: { id: huellaToken(token) } });
  almacen.delete(COOKIE_SESION);
}
```

```ts
"use server";
// Registro, entrada y salida. Una Server Action es un endpoint publico: todo lo que llega se valida aqui.
import { redirect } from "next/navigation";
import { Prisma } from "@/generated/prisma/client";
import { cifrarContrasena, comprobarContrasena } from "@/lib/contrasenas";
import { MAXIMO_CONTRASENA, destinoSeguro, validarRegistro } from "@/lib/cuentas";
import { prisma } from "@/lib/prisma";
import { cerrarSesion, iniciarSesion } from "@/lib/sesion";

export type EstadoFormulario = { error: string; valores?: { nombre?: string; email?: string } };

const YA_EXISTE = "Ya hay una cuenta con ese email: entra";
const INCORRECTOS = "Email o contraseña incorrectos";

const texto = (datos: FormData, campo: string) => String(datos.get(campo) ?? "");

export async function registrarse(_: EstadoFormulario, datos: FormData): Promise<EstadoFormulario> {
  const valores = { nombre: texto(datos, "nombre"), email: texto(datos, "email") };
  const contrasena = texto(datos, "contrasena");
  const r = validarRegistro({ ...valores, contrasena, repetir: texto(datos, "repetir") });
  if (!r.ok) return { error: r.error, valores };

  let usuarioId: number;
  try {
    const usuario = await prisma.usuario.create({
      data: { ...r.datos, contrasena: await cifrarContrasena(contrasena) }, // rol: CLIENTE por defecto
    });
    usuarioId = usuario.id;
  } catch (e) {
    // P2002 = email repetido (@unique). Tambien cubre dos registros a la vez con el mismo email
    if (e instanceof Prisma.PrismaClientKnownRequestError && e.code === "P2002") return { error: YA_EXISTE, valores };
    throw e;
  }

  await iniciarSesion(usuarioId);
  redirect(destinoSeguro(texto(datos, "destino"))); // fuera del try: redirect funciona lanzando un error especial
}

export async function entrar(_: EstadoFormulario, datos: FormData): Promise<EstadoFormulario> {
  const email = texto(datos, "email").trim().toLowerCase();
  const contrasena = texto(datos, "contrasena");
  const valores = { email: texto(datos, "email") };
  if (!email || !contrasena || contrasena.length > MAXIMO_CONTRASENA) return { error: INCORRECTOS, valores };

  const usuario = await prisma.usuario.findUnique({ where: { email } });
  if (!usuario) {
    // Calculamos un scrypt igualmente: asi un email inexistente tarda lo mismo y no se puede adivinar quien tiene cuenta
    await cifrarContrasena(contrasena);
    return { error: INCORRECTOS, valores };
  }
  if (!(await comprobarContrasena(contrasena, usuario.contrasena))) return { error: INCORRECTOS, valores };

  await iniciarSesion(usuario.id);
  redirect(destinoSeguro(texto(datos, "destino")));
}

export async function salir() {
  await cerrarSesion();
  redirect("/");
}
```

```tsx
"use client";
// Elige el carrito segun quien ha entrado y, al entrar, le suma lo que hubiera en el carrito anonimo.
// Sin sesion: "carrito-rincon". Con sesion: "carrito-rincon:<id>". No pinta nada.
import { useEffect } from "react";
import { CLAVE_CARRITO, claveCarrito, juntarCarritos, useCarrito, type LineaCarrito } from "@/store/carrito";

// Lo que persist guarda en localStorage es {"state":{"lineas":[...]},"version":0}
function leerLineas(clave: string): LineaCarrito[] {
  try {
    const guardado = JSON.parse(localStorage.getItem(clave) ?? "null");
    return Array.isArray(guardado?.state?.lineas) ? guardado.state.lineas : [];
  } catch {
    return [];
  }
}

export function SincronizarCarrito({ usuarioId }: { usuarioId: number | null }) {
  useEffect(() => {
    const clave = claveCarrito(usuarioId);
    let lineas = leerLineas(clave);
    if (usuarioId !== null) {
      // Lo anonimo se suma una sola vez: despues se vacia, y las siguientes visitas no suman nada
      const anonimo = leerLineas(CLAVE_CARRITO);
      if (anonimo.length > 0) {
        lineas = juntarCarritos(anonimo, lineas);
        localStorage.removeItem(CLAVE_CARRITO);
      }
    }
    // Primero se cambia la clave y despues el estado: setState escribe en la clave NUEVA
    // (al salir, el carrito del usuario se queda guardado en la suya y en memoria entra el anonimo)
    useCarrito.persist.setOptions({ name: clave });
    useCarrito.setState({ lineas });
  }, [usuarioId]);
  return null;
}
```

```ts
// Crea una cuenta de administrador o asciende una que ya existe. Es la UNICA forma de tener un ADMIN:
// la web solo crea clientes.
//   npm run crear-admin -- ana@ejemplo.com               (base de desarrollo, la del .env)
//   npm run crear-admin -- ana@ejemplo.com --produccion  (base de produccion, la de .env.produccion)
// Pide la contraseña por la terminal sin mostrarla. Si la cuenta existe, le pone esa contraseña nueva.
import { config } from "dotenv";
import { createInterface } from "node:readline";
import { PrismaPg } from "@prisma/adapter-pg";
import { PrismaClient } from "../src/generated/prisma/client";
import { cifrarContrasena } from "../src/lib/contrasenas";
import { MAXIMO_CONTRASENA, MINIMO_CONTRASENA } from "../src/lib/cuentas";

const args = process.argv.slice(2);
const produccion = args.includes("--produccion");
const email = args.find((a) => !a.startsWith("--"))?.trim().toLowerCase();

config({ path: produccion ? ".env.produccion" : ".env", quiet: true });

// Pregunta sin mostrar lo que se escribe (si la terminal lo permite)
function preguntarOculto(pregunta: string): Promise<string> {
  return new Promise((resolve) => {
    const rl = createInterface({ input: process.stdin, output: process.stdout, terminal: true });
    const salida = rl as unknown as { _writeToOutput: (s: string) => void };
    salida._writeToOutput = (s) => {
      if (s.includes(pregunta)) process.stdout.write(pregunta); // solo la pregunta, no las teclas
    };
    rl.question(pregunta, (respuesta) => {
      rl.close();
      process.stdout.write("\n");
      resolve(respuesta);
    });
  });
}

async function main() {
  if (!email || !/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email)) {
    throw new Error("Uso: npm run crear-admin -- <email> [--produccion]");
  }
  const url = process.env.DATABASE_URL;
  if (!url) throw new Error(`Falta DATABASE_URL en ${produccion ? ".env.produccion" : ".env"}`);
  console.log(`Base: ${produccion ? "PRODUCCION (la tienda publicada)" : "desarrollo (.env)"}`);

  const contrasena = await preguntarOculto("Contraseña: ");
  if (contrasena.length < MINIMO_CONTRASENA || contrasena.length > MAXIMO_CONTRASENA) {
    throw new Error(`La contraseña debe tener entre ${MINIMO_CONTRASENA} y ${MAXIMO_CONTRASENA} caracteres`);
  }
  if ((await preguntarOculto("Repítela: ")) !== contrasena) throw new Error("Las contraseñas no coinciden");

  const prisma = new PrismaClient({ adapter: new PrismaPg({ connectionString: url }) });
  try {
    const hash = await cifrarContrasena(contrasena);
    const usuario = await prisma.usuario.upsert({
      where: { email },
      create: { email, nombre: "Admin", contrasena: hash, rol: "ADMIN" },
      update: { contrasena: hash, rol: "ADMIN" },
    });
    // Las sesiones abiertas con la contraseña anterior se cierran
    await prisma.sesion.deleteMany({ where: { usuarioId: usuario.id } });
    console.log(`OK: ${usuario.email} es ADMIN (id ${usuario.id})`);
  } finally {
    await prisma.$disconnect();
  }
```

```tsx
import { formatearPrecio } from "@/lib/formato";
import { prisma } from "@/lib/prisma";
import { usuarioActual } from "@/lib/sesion";

type Props = { params: Promise<{ id: string }> };

export async function generateMetadata({ params }: Props): Promise<Metadata> {
  return { title: `Pedido #${(await params).id}` };
}

export default async function MiPedido({ params }: Props) {
  const { id: texto } = await params;
  const usuario = await usuarioActual();
  if (!usuario) redirect(`/entrar?callbackUrl=${encodeURIComponent(`/cuenta/pedidos/${texto}`)}`);

  const id = Number(texto);
  if (!Number.isInteger(id) || id <= 0) notFound();
  const pedido = await prisma.pedido.findUnique({
    where: { id },
    include: { lineas: { include: { producto: { select: { nombre: true } } } } },
  });
  if (!pedido || !puedeVerPedido(usuario, pedido)) notFound();

  return (
    <main className="mx-auto flex max-w-3xl flex-col gap-6 px-6 py-10">
      <Link href="/cuenta/pedidos" className="text-sm text-muted-foreground hover:text-foreground">← Mis pedidos</Link>
      <div className="flex items-center gap-3">
        <h1 className="text-3xl font-bold tracking-tight">Pedido #{pedido.id}</h1>
        <BadgeEstado estado={pedido.estado} />
      </div>
      <p className="text-sm text-muted-foreground">
        {pedido.creadoEn.toLocaleString("es-ES", { timeZone: "Europe/Madrid" })} · {pedido.email}
      </p>
      <div className="rounded-xl border p-5">
        <ul className="space-y-1 text-sm">
          {pedido.lineas.map((l) => (
            <li key={l.id} className="flex justify-between">
              <span>{l.cantidad} × {l.producto.nombre}</span>
              <span className="tabular-nums">{formatearPrecio(l.precioUnitario * l.cantidad)}</span>
            </li>
          ))}
        </ul>
        <p className="mt-3 flex justify-between border-t pt-3 font-semibold">
          <span>Total</span><span>{formatearPrecio(pedido.total)}</span>
        </p>
      </div>
    </main>
  );
}
```
